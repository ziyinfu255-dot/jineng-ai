# Xiaohongshu Marketing Copy

Use this only when the user asks for marketing, listing, or Xiaohongshu copy.

## Default output

Produce three complete posts with distinct angles:

1. **Teacher pain point**: opening-term preparation pressure, classroom readiness, and reduced preparation work.
2. **Course content**: lesson flow, representative activities, student outcomes, and package contents.
3. **Emotional story**: the topic's core metaphor, student growth, and a warm teacher perspective.

Each post should include:

- a concise Xiaohongshu-style title;
- 3-6 short body paragraphs;
- concrete package facts;
- a light call to action;
- 6-10 relevant hashtags.

## Accuracy rules

- Use the actual slide count, duration, audience, presenter role, and included files.
- Mention the preview edition only when it exists.
- Do not claim `可编辑`, `原创`, `全网首发`, comment volume, sales volume, or teacher outcomes unless verified.
- Do not treat “求课件” comments as proof of instructional quality.
- Avoid copying another post's distinctive wording or title.
- Keep emojis restrained and useful for scanning.

## Recommended fact order

1. Grade + scenario + topic.
2. The teacher or student problem solved.
3. The lesson's 3-5 major phases.
4. Package contents: PPT, lesson plan, detailed script, preview, printable activity when present.
5. Suitable user and class duration.
6. Call to view the preview or learn more.
